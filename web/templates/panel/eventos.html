Reprocesar o descartar

Desde aquí no se cambia nada. Para volver a publicar un fallido o borrarlo después de revisarlo, corre en la terminal, desde la raíz del proyecto:

  • docker compose exec svc-contenido python -m agroia_comun.eventos reprocesar --id <id>
  • docker compose exec svc-contenido python -m agroia_comun.eventos descartar --id <id>
  • docker compose exec svc-contenido python -m agroia_comun.eventos estado

El motivo aquí es solo el nombre de la excepción; el texto completo se ve con el comando estado. Los fallidos sin sus datos (por ejemplo, una pregunta a la IA) no se pueden reprocesar: se descartan. Detalle en docs/eventos.md, «Operación».
